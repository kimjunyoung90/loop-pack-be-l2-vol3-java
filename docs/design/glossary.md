# 유비쿼터스 언어 정의 (Glossary)

각 바운디드 컨텍스트에서 사용하는 핵심 개념과 상태를 변경하는 행위를 정의한다.

## 사용자 컨텍스트

| 용어 | 영문 | 정의 |
|------|------|------|
| 사용자 | User | 서비스를 이용하는 주체 |
| 회원가입 | SignUp | 사용자가 서비스에 새로운 계정을 생성하는 행위 |
| 로그인 | Login | 사용자가 자신의 계정으로 서비스에 인증하는 행위 |

## 브랜드 컨텍스트

| 용어 | 영문 | 정의 |
|------|------|------|
| 브랜드 | Brand | 상품을 판매하는 주체. 이름을 가진다 |
| 브랜드 등록 | BrandRegistration | 관리자가 새로운 브랜드를 등록하는 행위 |
| 브랜드 수정 | BrandModification | 관리자가 브랜드 정보를 변경하는 행위 |
| 브랜드 삭제 | BrandDeletion | 관리자가 브랜드를 삭제하는 행위 |

## 상품 컨텍스트

| 용어 | 영문 | 정의 |
|------|------|------|
| 상품 | Product | 판매 가능한 항목. 이름과 가격을 가진다 |
| 재고 | Stock | 상품의 판매 가능한 수량 |
| 상품 등록 | ProductRegistration | 관리자가 새로운 상품을 등록하는 행위. 상품이 속할 브랜드가 사전에 등록되어 있어야 한다 |
| 상품 수정 | ProductModification | 관리자가 상품 정보를 변경하는 행위 |
| 상품 삭제 | ProductDeletion | 관리자가 상품을 삭제하는 행위 |

## 좋아요 컨텍스트

| 용어 | 영문 | 정의 |
|------|------|------|
| 좋아요 | Like | 사용자가 특정 상품에 관심을 표시하는 행위 |
| 좋아요 취소 | Unlike | 사용자가 좋아요를 철회하는 행위 |
| 좋아요 수 | LikeCount | 상품에 등록된 좋아요의 합계 |
| 좋아요 수 증가 | IncrementLikeCount | 좋아요 등록 시 상품의 좋아요 수를 1 증가시키는 행위 |
| 좋아요 수 감소 | DecrementLikeCount | 좋아요 취소 시 상품의 좋아요 수를 1 감소시키는 행위 |

## 주문 컨텍스트

| 용어 | 영문 | 정의 |
|------|------|------|
| 주문 | Order | 사용자가 상품 구매를 요청하는 행위 |
| 주문항목 | OrderItem | 주문에 포함된 개별 상품, 수량, 가격 |
| 주문취소 | OrderCancellation | 사용자가 주문을 철회하는 행위 |
| 상품 총액 | Total Amount | 할인 적용 전 주문항목 가격의 합계 |
| 할인 금액 | Discount Amount | 쿠폰 적용으로 차감되는 금액 |
| 최종 결제 금액 | Final Amount | 상품 총액에서 할인 금액을 차감한 실제 결제 금액 |
| 쿠폰 적용 | Coupon Application | 주문 생성 시 사용자 쿠폰을 적용하여 할인을 받는 행위 |
| 쿠폰 복원 | Coupon Restoration | 주문 취소 시 사용된 쿠폰을 사용 가능 상태로 되돌리는 행위 |

## 쿠폰 컨텍스트

| 용어 | 영문 | 정의 |
|------|------|------|
| 쿠폰 | Coupon | 할인 혜택을 정의한 원본. 관리자가 등록하며, 이를 바탕으로 사용자에게 발급된다 |
| 쿠폰 등록 | CouponRegistration | 관리자가 새로운 쿠폰을 등록하는 행위 |
| 쿠폰 수정 | Coupon Modification | 관리자가 쿠폰 정보(쿠폰명, 할인 유형, 할인 값, 최소 주문 금액, 유효기간)를 변경하는 행위. 발급된 사용자 쿠폰이 없는 경우에만 가능하다 |
| 쿠폰 발급 요청 | Coupon Issue Request | 사용자가 쿠폰 발급을 요청하는 행위 |
| 사용자 쿠폰 | User Coupon | 사용자가 발급받은 쿠폰 |
| 할인 유형 | Discount Type | 쿠폰의 할인 방식. 정액과 정률이 있다 |
| 정액 할인 | Fixed | 고정 금액을 할인하는 방식 |
| 정률 할인 | Rate | 비율(%)로 할인하는 방식 |
| 쿠폰 상태 | Coupon Status | 사용자 쿠폰의 상태 |
| 쿠폰 사용 | Coupon Use | 사용자 쿠폰이 주문에 사용되어 사용 완료 상태로 변경되는 행위 |
| 사용 가능 | Available | 사용자 쿠폰을 사용할 수 있는 상태 |
| 사용 완료 | Used | 사용자 쿠폰이 주문에 적용되어 사용된 상태 |
| 만료 | Expired | 사용자 쿠폰의 유효기간이 지나 사용할 수 없는 상태 |

## 결제 컨텍스트

| 용어 | 영문 | 정의 |
|------|------|------|
| 결제 | Payment | 주문에 대한 결제 시도 및 그 결과를 기록하는 객체 |
| 결제 요청 | PaymentRequest | 사용자가 주문에 대해 결제를 요청하는 행위 |
| 결제 상태 | PaymentStatus | 결제의 진행 상태 (대기중, 알수없음, 성공, 실패) |
| 결제 승인 | PaymentApproval | PG사에서 결제를 승인하여 성공 상태로 전이하는 행위 |
| 결제 거절 | PaymentRejection | PG사에서 결제를 거절하여 실패 상태로 전이하는 행위 |
| 거래 키 | TransactionKey | PG사에서 발급하는 결제 거래 고유 식별자 |
| 카드 종류 | CardType | 결제에 사용하는 카드사 (삼성, KB, 현대) |
| 결제 상태 불명 | PaymentUnknown | 타임아웃 등으로 PG 요청 도달 여부를 확인할 수 없는 상태 |
